CONTRACT & ARCHITECTURAL NOTES:
- Fit Adapter Contract: Implemented in [lib/fit.ts](file:///e:/1.%20vietmix/lib/fit.ts) following the P2 specification: $x_{out} = x + \text{scale} \cdot x_{in}$ and $y_{out} = y + \text{scale} \cdot y_{in}$ over a 1080x1920 logical canvas with top-left origin. Coordinates are mapped to CSS percentage transforms. Missing or invalid entries safely default to identity `{x: 0, y: 0, scale: 1}` without throwing errors.
- Asset Sync Behavior: Implemented in [scripts/sync_assets.mjs](file:///e:/1.%20vietmix/scripts/sync_assets.mjs). It runs automatically during `predev` and `prebuild` (and via `npm run sync:assets`), copying the 22 placeholder PNGs from `assets/<gender>/` into `public/assets/<gender>/`. The destination directory `public/assets/` is ignored by Git in `.gitignore`.
- Placeholder Limitations: The placeholder images from Phase 0 are rectangular color-coded blocks designed for slot testing. They do not have anatomical contouring, tailored necklines, or visual draping. Real photographic garments and character assets will be aligned in Phase 3a.
- Visual Checks Not Performed: UI interactions, accessibility attributes, keyboard focus rings, and layout structures were verified programmatically using React Testing Library and JSDOM across 100 automated test cases. Live rendering on physical mobile screens and visual fidelity across Safari/WebKit were not visually inspected by human eye.
